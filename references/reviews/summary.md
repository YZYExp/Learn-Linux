# 《Linux，自底向上》独立交叉审稿与修订记录

审稿日期：2026-10-22。审稿基线：第 1.0 版，Git `a052588`。交付版本：第 1.1 版。

## 审稿结论

本轮未发现需要推翻全书主线的重大机制错误。确认并修订 2 项技术表述问题、2 项跨章与目录一致性问题、1 项交付构建问题，另采纳 3 项有助于避免误读的边界补充。不能将“未发现重大错误”理解为全版本、全实现的正确性认证。

## 范围与方法

三位独立审稿者分别通读运行基础、文件/I/O/网络、隔离/虚拟化/平台专题，主审通读导读、桌面、可观测性、综合案例和附录并整合。覆盖全部 20 章正文及对应 20 幅机制图的标签与关系；重点事实重新打开原始资料核对，核查引用究竟支持哪项命题，而非只检查 URL 存在。

本轮未逐句穷尽重审全部 148 个来源页面，也没有进行完整源码审计、特权行为测试或用户设备测量。图解语义审读与渲染检查分别记录，不把 XML 合法等同于排版正确。

## 关键证据

- [Control Group v2，CPU Interface Files](https://docs.kernel.org/admin-guide/cgroup-v2.html#cpu-interface-files)：区分公平调度、具有对应回调的 BPF 调度器与其他策略，支持 CR-01。
- [execve(2)](https://man7.org/linux/man-pages/man2/execve.2.html) 与 [ld.so(8)](https://man7.org/linux/man-pages/man8/ld.so.8.html)：程序映像替换及动态加载器职责，支持 CR-02。
- [Ramfs、rootfs 与 initramfs](https://docs.kernel.org/filesystems/ramfs-rootfs-initramfs.html)：真实根的说明带有“if any”条件，支持 CR-03。
- [fork(2)](https://man7.org/linux/man-pages/man2/fork.2.html)：调用线程、同步对象状态与 exec 前限制，支持 CR-04。
- [AIDL for HALs](https://source.android.com/docs/core/architecture/aidl/aidl-hals)：system/vendor 等 Android 组件边界，支持 CR-05。
- CR-06、CR-07 由工程中实际章序、首标题与清单对比确定；CR-08 通过读取旧工程包内 EPUB、对嵌入 PNG 实际解码复现，不依赖外部资料。

## 核对后保留的关键内容

VFS 的 fd/打开状态区别，fsync 与 rename 的持久化边界，FUSE 的写回缓存前提，OverlayFS 与 OCI 删除标记的表示差异，容器 PID 1 与 rootless 边界，KVM 退出和设备后端分工，QEMU 的执行与接口转换，BTF/CO-RE 的能力边界，以及 XNU/Horizon 的证据身份，均有对应原始资料支持。本轮未因未列尽所有细节而把正确的科普简化判为错误。

两个可选扩写暂未加入正文：io_uring 的 multishot 请求可能产生多个完成条目；文件映射也可能保持引用。现文没有作相反保证，故不计为勘误。它们保存在专题审稿意见中，供今后深化使用。

## 修订版验证

修订同步进入分章 Markdown、图解源与生成器；重新生成机制图、合订主稿及 EPUB。章节清单、标题、相对资源、引用登记和 Git 初始历史均重新检查。EPUB 核查 XML、包内图片路径以及全部 21 幅 PNG（含封面）的完整像素解码；图 02、05 另行渲染查看。工程包保留分专题审稿原始意见及本处理记录。

EPUB 未逐一在所有商业阅读器测试；本轮没有新增性能结论或具体硬件兼容保证。审稿过程不等于对全书全部可能行为的实验验证。
